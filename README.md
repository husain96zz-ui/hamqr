# HAMQR — منصة المنيو الرقمي

نسخة Frontend تجريبية عربية RTL لمنصة SaaS متعددة المطاعم.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## الموجود في النسخة
- الصفحة الرئيسية التسويقية
- هوية HAMQR داكنة/ذهبية
- عرض منيو مطعم
- لوحة تحكم تجريبية
- الباقات والاشتراكات
- نموذج تسجيل تجريبي
- تصميم Responsive للموبايل

## المرحلة الإنتاجية التالية
ربط Backend وقاعدة بيانات، تسجيل المستخدمين، إدارة المطاعم والفروع والأصناف، رفع الصور، توليد QR فعلي، بوابة دفع، صلاحيات الموظفين، وإحصائيات حقيقية.
